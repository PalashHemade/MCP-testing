# Frontend

React + TypeScript + Vite + Tailwind CSS v4 + React Query chat UI for the
Logistics AI Chatbot demo. See the [repo root README](../README.md) for full
setup instructions and the [docs/](../docs/) folder for architecture details.

```bash
cp .env.example .env.local   # set VITE_API_BASE_URL if the backend isn't on :8000
npm install
npm run dev                  # http://localhost:5173
npm run build                # production build -> dist/
npm run lint                 # oxlint
```
